# ⚡ Ray AI

A modern, proprietary conversational AI companion designed with an **adaptive best-friend persona**, multimodal vision, image generation, and intelligent usage limits.

---

## ✨ Features

1. **Ray Interface & Aesthetic**:
   - Deep dark mode (`#131314` background), modern typography, and smooth gradient glows.
   - Real-time markdown support with syntax highlighted code blocks and one-click copy buttons.
   - Collapsible sidebar for conversation history, quick starter topics, and profile status.

2. **Ray Intelligence Engine**:
   - High-speed language reasoning and comprehension powered by the platform's core engine.
   - Zero configuration needed for end users — fully configured out of the box.

3. **Strict Guest & Member Limits**:
   - **4 Questions Without Signing In**: Guests can ask up to 4 questions. On the 5th attempt, Ray prompts them to sign in or create a free account.
   - **Unlimited Questions When Signed In**: Create a free account (or click the 1-click Demo Login) to chat endlessly with Ray without restrictions.
   - **Image Creation Limit (Max 5)**: Create up to 5 custom artwork images with the AI generator.
   - **Image Upload Limit (Max 5)**: Upload up to 5 photos for Ray Vision analysis.

4. **Adaptive Friend Persona & Real-Time Vibe Radar**:
   - Talks and acts like a loyal, funny, empathetic friend.
   - Dynamically analyzes speaking tone:
     - Slang & chill texting (*"yo", "bro", "fr", "ngl"*) ➔ Adapts to a relaxed, casual vibe.
     - Excitement & exclamation marks ➔ Matches your hype with high energy.
     - Vulnerable or deep thoughts ➔ Provides thoughtful, comforting, and heartfelt support.
   - The top navigation bar and message bubbles display a live **"Friend Vibe"** badge in real time!
